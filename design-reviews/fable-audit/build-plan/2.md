### Q4 — Fix invalid `@supports` grammar in the GHOST wordmark invisibility fallback

**Where:** Title screen / `.word1` gradient wordmark fallback — `index.html` inline `<style>`, the `@supports` rule immediately following the `.word1` gradient-clip declaration (~line 890). This class is shared by the title "GHOST", the game-over score, and "PAUSED".

**What (mockup-ready):** Correct the syntactically invalid `@supports` condition that is supposed to protect the gradient/transparent-fill wordmark from becoming invisible on engines without `background-clip: text` support.

- Current (broken): `@supports not (background-clip: text) and not (-webkit-background-clip: text) { .word1 { -webkit-text-fill-color: var(--accent); color: var(--accent); } }`
- This combines a `not` term with `and` without parenthesizing each operand, which violates the CSS Conditional Rules Module grammar. Conforming parsers drop the entire block — the fallback can never fire, on any engine, including the ones it exists for.
- Corrected: `@supports not ((background-clip: text) or (-webkit-background-clip: text)) { .word1 { -webkit-text-fill-color: var(--accent); color: var(--accent); } }`
- This is logically equivalent (De Morgan's: NOT(A) AND NOT(B) ≡ NOT(A OR B)) but now legally parenthesized, so it parses and applies. No visual change on any current major browser (all support `background-clip: text`) — the fix only activates the pre-existing intended fallback on engines lacking that support (older WebKit builds, certain forced-colors/high-contrast contexts, etc.), preventing the title, game-over score, or PAUSED label from silently vanishing.

**Why:** This is a one-line syntax fix to dead fallback CSS, not a redesign — it makes the failure floor for the single most important first-impression element (the title wordmark) actually deploy as the adjacent code comment already promises ("Fallback: if background-clip:text is unsupported... Force a solid accent fill instead"). Grounded in finding **L1-F7** (`design-reviews/fable-audit/02_findings.md:100-105`), which documents exactly this defect and evidence-cites `index.html:890`. Serves the player-learner test by protecting the FUN first-impression moment (the title never silently blanks) and serves the taste anchor by making the design system's own stated fallback contract actually true rather than aspirational.

**Player/Learner impact + Craft/Cohesion:** Presentation-only, zero gameplay/scoring/curriculum/direction-mapping effect. Protects the title, game-over score, and PAUSED label from ever silently vanishing on an affected engine — a floor-level craft fix that makes the codebase's documented intent match its actual behavior, closing a gap that a source-reading reviewer would otherwise flag as broken/dead code.

**Accessibility note:** Serves WCAG 2.2 AA 1.4.3 Contrast (Minimum) and general text perceivability — an invisible wordmark is an infinite-contrast failure for anyone on an affected engine. Trades nothing away: the fallback reuses the existing `var(--accent)` design-system token (same color already used elsewhere), so contrast against the existing background matches the originally intended design. No change to motion, reduced-motion handling, photosensitivity properties, focus visibility, or color-alone signaling — not-color-alone, photosensitivity, and reduced-motion properties are all preserved unmodified.

**Effort:** S — trivial single CSS selector edit, no HTML/JS/build changes, under 5 minutes. No dependencies or conflicts with other proposals.
